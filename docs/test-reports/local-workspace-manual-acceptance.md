# 本地会议工作区人工验收清单

> 适用范围：`LocalWorkspacePanel` 的目录授权、资料导入与纪要导出。
> 自动化限制：目录选择依赖浏览器原生 `showDirectoryPicker()`，Playwright 无法驱动系统目录选择框，因此只能人工验收；自动化用例仅覆盖浏览器不支持时的降级提示（`frontend/e2e/local-workspace.spec.ts`）。

## 一、前置条件

- [ ] 使用支持 File System Access API 的 Chromium 系浏览器（Chrome / Edge，建议最新稳定版）。
- [ ] 通过 `http://localhost:5173` 或 HTTPS 访问（`localhost` 属于安全上下文）。
- [ ] 前后端与数据库已启动，且当前账号可正常创建会议、上传资料。
- [ ] 准备一个本地文件夹，包含：
  - 至少 1 个可解析资料：`sample.txt`、`sample.docx` 或 `sample.pdf`
  - 至少 1 个应被忽略的文件：`ignored.png`
- [ ] 目标会议中至少存在 1 份纪要；若没有，先到「纪要」小节生成一份。

## 二、验收步骤与预期

| # | 步骤 | 预期结果 | 实际结果 | 证据 |
| --- | --- | --- | --- | --- |
| 1 | 登录后进入任意会议详情，打开「材料」小节 | 页面显示「本地会议工作区」以及「选择本地文件夹」按钮 | 待执行 |  |
| 2 | 点击「选择本地文件夹」，选择一个准备好的本地文件夹 | 出现浏览器原生授权提示；授权后显示「已选择：<文件夹名>」，并列出 PDF / DOCX / TXT 文件 | 待执行 |  |
| 3 | 检查文件列表 | 只显示受支持资料；`ignored.png` 不出现在列表中；显示文件大小 | 待执行 |  |
| 4 | 点击「导入资料（N 个）」 | 逐个上传，显示「已导入 N 个文件」；「材料」列表出现同名资料；失败文件以文件名 + 错误原因列出 | 待执行 |  |
| 5 | 点击「导出最新纪要」 | 显示「最新纪要已导出到本地文件夹」；授权文件夹中出现 `<会议标题>-会议纪要.docx`，可正常打开 | 待执行 |  |
| 6 | 在会议无纪要时点击「导出最新纪要」 | 显示「当前会议还没有可导出的纪要」，不写入空文件 | 待执行 |  |
| 7 | 将会议归档后回到「材料」小节 | 可导出纪要；「导入资料」按钮不可用，并提示已归档不能导入 | 待执行 |  |
| 8 | 浏览器权限失效后重试（刷新页面或重新授权） | 操作给出明确错误；重新选择目录后可继续导入/导出，不静默丢失 | 待执行 |  |
| 9 | 选择空文件夹或仅含不支持文件的文件夹 | 显示「文件夹中没有 PDF / DOCX / TXT 资料」，导入按钮禁用 | 待执行 |  |
