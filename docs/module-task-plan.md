# 模块开发任务规划

> 本文件由《AI 会议个人助理——模块详细开发任务文档》整理而成，作为模块拆分、负责人、优先级与验收条件的协作基线。

## MVP 核心闭环

1. 会前准备：创建会议 → 导入资料 → AI 理解会议背景 → 生成准备清单
2. 会中记录：手动记录会议内容 → AI 问答 → 标记重点和问题
3. 会后整理：生成纪要 → 用户确认 → 提取行动项和未解决问题
4. 个人任务跟进：确认个人行动项 → 创建任务 → 更新状态 → 追溯来源会议

## 角色

- **A**：系统与后端集成（工程骨架、认证、会议 CRUD、任务、数据库、权限、部署）
- **B**：AI 后端（文档解析、LLM、Embedding、RAG、Prompt、纪要/行动项提取）
- **C**：前端与用户体验（Vue 页面、状态交互、前端测试）

所有人参与接口评审、代码审查和端到端测试。

## M00 工程基础与开发规范（第一阶段）

开发目标：建立三人共同开发的基础环境、统一代码规范和持续集成流程。

| 编号 | 任务 | 负责人 | 验收标准 | 状态 |

| M00-04 | 初始化 FastAPI 项目与健康检查接口 | A | 后端可以正常启动并返回健康状态 | 已完成 |

| M00-06 | 配置 SQLAlchemy、Alembic、Pydantic | A | 能执行初始数据库迁移 | 已完成 |

## 开发执行原则

1. **先接口，后并行**：数据模型和 API 契约先评审，前端与后端再并行实现。
2. **先闭环，后扩展**：每个阶段完成真实可操作的业务流程，再开始下一阶段。
3. **先保证业务正确，再优化 AI**：用户权限、数据持久化、来源追溯和人工确认是底线。
