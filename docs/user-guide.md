# OpenMIND 使用说明

面向用户的使用指南。技术设计与接口契约见 `docs/ai-design.md`、`docs/api.md`。

---

## 一、AI 问答的能力边界（请先阅读）

### 1. 会议转写记录不进入语义检索

- 会议中的 **ASR 转写记录**以及确认后生成的**会议记录**，**不会被写入向量库**，不参与语义检索。
- 也就是说：对较早的转写内容提问时，系统**不会**像搜索引擎那样在全部历史记录中做相似度匹配。

### 2. 回答问题时，记录仅提供"最近有限条"上下文

- 问答时系统会额外附带**当前会议的最近 20 条、合计不超过 8000 字符**的记录片段，作为回答的辅助上下文；
- 超出该范围的记录内容**不参与本次回答**；
- 该范围是当前阶段的刻意设计（完整历史记录检索需要独立的检索设计，尚未实现），并非缺陷。

### 3. 语义检索的真正来源

| 来源 | 说明 |
| --- | --- |
| **会议材料** | 上传的 PDF / DOCX / TXT 解析后的正文（按"当前会议"或"全部历史会议"范围检索） |
| **个人知识库** | 在设置中上传的个人文档；需在提问时**显式选择**知识库范围，不与会议内容混检 |

### 4. 如何理解回答

- 回答中的每个引用都会标注**来源**：会议材料 / 会议记录 / 个人知识库 / 联网检索（含链接）；
- 当材料不足以回答时，系统会**明确说明无法确认，而不是编造**；
- 只有在会议材料与记录都完全找不到证据时，才会触发**联网检索补救**，且回答会标注"基于联网检索，仅供参考"；
- 针对超出上述范围的问题（例如很久之前的转写细节），检索不到属正常现象，可尝试上传相关材料或改用知识库。

### 5. 用户画像（记忆中心）的作用

- 你填写的角色、工作场景、表达偏好仅用于**调整回答的表达方式**；
- 它**不会**覆盖材料中的事实、来源与业务规则，也不会被用于检索排序。

## 二、常见问题

**Q：为什么有些转写内容问不到？**
A：转写记录不进向量库，且仅提供最近有限条记录上下文（见上文 1、2）。属于当前阶段的能力边界。

**Q：回答引用的来源可以点开吗？**
A：会议材料与知识库来源展示文件名/片段；联网来源可直接点击链接跳转。

**Q：我的资料会被别人搜到吗？**
A：不会。所有检索都在服务端按你的账号过滤，跨用户内容不可见。
